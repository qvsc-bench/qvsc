Does the quantum solver beat the best classical one? Let's check.

QvsC (Quantum vs Classical) is an open benchmark for combinatorial optimization. Quantum, hybrid and classical solvers run on the same fixed instances, and every result is recomputed from the submitted solution. No accounts, no fees, no trust required.

Submit a result See the leaderboard

Why this exists

Same instances

Fixed, versioned instance sets with hashes and best-known values. No cherry-picking.

Strong classical baselines

Quantum claims are measured against good classical solvers, not weak strawmen.

Verified, not reported

CI checks every solution file. A number appears only if the solution is feasible.

Fair accounting

Quantum entries state device, shots, device time and any classical post-processing.

Submit a result

Results enter through a GitHub pull request. Quantum and hybrid entries are especially welcome; so are stronger classical solvers, which raise the bar for everyone.

  1. Fork qvsc-bench/qvsc and add a folder under problems/mis/submissions/.
  2. Put in it a submission.toml (method, paradigm, hardware, time budget) and one .sol file per instance you solved.
  3. Run python -m qvsc.mis.leaderboard --check and open the pull request. On merge, the leaderboard updates itself.
