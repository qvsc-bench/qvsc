# K-SAT instances: sources and licences

QvsC does not redistribute the K-SAT instances. `python -m qvsc.ksat.fetch` downloads them from the
original publishers and checks each formula against the hash in `index.csv.gz`. Cite the original
source of the instances you use.

## RandCSPBench

Random K-SAT formulas generated by `datasets/gen_graphs_sat.jl` of
[RandCSPBench](https://github.com/ArtLabBocconi/RandCSPBench): N variables, M = round(α N) clauses,
each clause with K distinct variables chosen uniformly and each literal negated with probability 1/2.
The random number generator is `StableRNG(17 + N)`.

| K | Split | N | α grid | Per (N, α) | In QvsC |
|--:|:--|:--|:--|--:|--:|
| 3 | `test` | 16, 32, 64, 128, 256 | 3.0, 3.1, …, 5.0 | 400 | 42,000 |
| 3 | `test_ood` | 512, 1024 | 3.0, 3.1, …, 5.0 | 400 | 16,800 |
| 4 | `test` | 16, 32, 64, 128, 256 | 8.0, 8.1, …, 10.0 | 200 | 21,000 |
| 4 | `test-ood` | 512, 1024 | 8.0, 8.1, …, 10.0 | 200 | 8,400 |

These are exactly the instances behind Table 1 (N ≤ 256) and Supplementary Table 1 (N = 512, 1024) of
the paper. `kSAT.zip` also contains the training sets and larger out-of-distribution sizes (3-SAT up to
N = 8192, 4-SAT up to N = 2048), for which the paper reports only some algorithms; they are not
indexed yet.

`paper_solved` = 1 when at least one algorithm evaluated in the paper solved the instance
(`results_evaluation/analysis-results/<K>SAT-best_per_sample.csv`). This includes algorithm variants
that QvsC does not show as rows (for example supervised NeuroSAT), as in the paper.
Satisfiability is not proven for the other instances: near and above the threshold, most of them are
unsatisfiable, but some may be satisfiable and just hard.

## Pelofske et al. (2023)

The random MAX 3-SAT instances of *High-Round QAOA for MAX k-SAT on Trapped Ion NISQ Devices*
(Pelofske, Bärtschi, Golden, Eidenbenz, 2023): one instance for each N = 6, …, 22, with 4N clauses
("clause density 4"). The Zenodo dataset gives each instance as lists of variables and signs, the
maximum number of satisfiable clauses `max_obj`, trained QAOA angles, the QASM circuits and the raw
measurements on Quantinuum H1-1, IonQ Harmony, IonQ Aria 1 and IonQ Forte. `qvsc.ksat.fetch` writes
the instances as DIMACS files `pelofske2023/k3_n<N>.cnf` (variable i of the dataset is variable i+1
here; sign 1 = positive literal). Some clauses are repeated, as in the dataset.

`optimum_unsat` is proven by exhaustive search over all 2^N assignments
(`baselines/exhaustive.cpp`) and equals M − `max_obj` on all 17 instances. Four instances are
unsatisfiable (N = 6, 19, 20, 21: optimum 1 unsatisfied clause).

## SATLIB uf20-91

The 1000 "uniform random 3-SAT" instances with 20 variables and 91 clauses (α = 4.55) of SATLIB.
SATLIB states that all `uf` instances are satisfiable; exhaustive search confirms it
(`optimum_unsat` = 0). The files end with a `%` line and a stray `0`, which the reader ignores.

## `index.csv.gz` columns

| Column | Meaning |
|:--|:--|
| `name` | QvsC instance name: `<K>SAT_<split>_N<N>_M<M>_id<i>`, `pelofske_k3_n<N>`, `satlib_uf20-<i>` |
| `source`, `path` | where the file comes from, and its path below the `--out` folder of `qvsc.ksat.fetch` (for RandCSPBench, the path inside `kSAT.zip`) |
| `k`, `n`, `m`, `alpha` | clause length, variables, clauses, density of the generation grid |
| `split` | RandCSPBench split, `hardware` or `uf20-91` |
| `tracks` | `;`-separated leaderboard tracks |
| `cnf_sha256` | first 16 hex digits of the SHA-256 of the canonical text of the formula (`qvsc.ksat.cnf.cnf_hash`: header and clauses in file order, single spaces). Independent of comments, whitespace and compression |
| `paper_solved` | see above (RandCSPBench only) |
| `optimum_unsat` | proven minimum number of unsatisfied clauses; empty when not proven |
| `sat_source` | first verified QvsC submission that reaches the target (0 unsatisfied clauses, or the proven optimum) |
| `status` | `optimum-proven`, `sat-verified` (a QvsC submission satisfies it), `sat-reported` (only the paper reports a solution) or `open` (nobody reports one) |
